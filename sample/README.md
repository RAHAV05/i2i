## 📸 File Catalog & Screen References

### 1. `01_active_camp_dashboard.png` (also `05_active_camp_overview_full.png`)
- **Theme / Role**: Active Health Camp Progress & Quick Stat Cards.
- **Key UI Elements**:
  - **Greeting Header**: Clean greeting (`Good morning / Dr. Adda`) with dark circular doctor monogram avatar (`P`).
  - **Active Camp Hero Banner**: Deep midnight navy rounded card (`#101F30` / `#0F2036`).
    - Radial progress dial on left with golden-amber progress ring (`65% done`, `#F59E0B`).
    - Right side details: "Active camp", Camp name ("St. Mary's School, Adyar"), Quota subtitle ("78 of 120 forms · 16 Oct").
  - **3 Pastel Metric Tiles**:
    - `168 Scanned` (soft mint `#E8F3F1`).
    - `9 To check` (warm cream `#FEF3D6`).
    - `3 Camps` (soft sage `#E5F0EB`).
  - **Camp Section**: "Your camps" header with "+ New camp" trigger.
